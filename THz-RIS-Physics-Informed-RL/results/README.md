# Results

This directory contains saved MATLAB result files supplied with the project.

`stage7_montecarlo_results.mat` is generated by `src/stage7_full_csi_montecarlo.m`. It was not present in the source ZIP used to build this repository, so it is intentionally not fabricated here. Run Stage 7 to regenerate it.

The included Stage 6 and Stage 9 result files are the saved outputs supplied with the original code package.

# Trained Agents

Saved MATLAB PPO agents supplied with the project.

- `stage8_trained_agent.mat`: vanilla PPO agent used by the standard Stage 8/9 robustness workflow.
- `stage8_trained_agent_domainrand.mat`: domain-randomized observation-noise training variant.
- `stage8_trained_agent_seed42.mat` ... `seed46.mat`: independent multi-seed training runs.
